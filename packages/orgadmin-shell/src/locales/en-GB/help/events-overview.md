# Events Module Help

## Managing Events

Create and manage all types of events for your organisation.

## Event Setup

### Basic Information
- Event name and description
- Date and time
- Location (physical or virtual)
- Capacity limits

### Registration
- Enable/disable registration
- Set registration deadlines
- Collect additional information via forms
- Manage waitlists

### Communication
- Send event announcements
- Reminder emails
- Post-event follow-ups

## Event Status

Events can be:
- **Draft** - Not yet published
- **Published** - Open for registration
- **Full** - Capacity reached
- **Closed** - Registration ended
- **Completed** - Event has occurred

## Attendee Management

View registrations, check in attendees, and manage cancellations from the event detail page.
