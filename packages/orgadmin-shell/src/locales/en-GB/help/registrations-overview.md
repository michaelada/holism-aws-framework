# Registrations Module Help

## Managing Registrations

The Registrations module handles sign-ups and enrolments for your organisation's programmes and activities.

## Registration Types

Create different registration categories:
- Programme enrolments
- Class sign-ups
- Activity registrations
- Seasonal registrations

Each type can have:
- Custom pricing
- Capacity limits
- Date restrictions
- Required forms

## Registration Database

View and manage all registrations:
- Search and filter registrations
- View registration details
- Process payments
- Export registration data

## Discounts

Offer discounts on registrations:
- Early bird pricing
- Multi-registration discounts
- Member discounts
- Promotional codes
