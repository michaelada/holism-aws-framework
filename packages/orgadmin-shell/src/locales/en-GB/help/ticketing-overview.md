# Event Ticketing Help

## Managing Event Tickets

The Ticketing module provides an overview of ticketing across all your events.

## Ticketed Events

View all events that have ticketing enabled:
- Event name and dates
- Ticket types and pricing
- Sales status and availability
- Revenue tracking

## Ticketing Settings

Configure ticketing for each event:
- Enable or disable ticketing
- Set ticket types and prices
- Define capacity limits
- Configure sales periods

## Ticket Sales

Monitor ticket sales:
- Real-time sales data
- Tickets sold vs. available
- Revenue per event
- Attendee lists
